Merchant RPG Simulator

Unofficial balancing tools for Merchant: crafting profit, essence sources, save viewer and battle simulation.

Tools

  • Save viewer

    Load your save file in the browser to see heroes, gear, inventory and maps. Nothing is uploaded: the file is read locally.

    Available

  • Profit calculator

    Rank items by sell value against full production cost (quests, maps, crafting, ascension, enchanting).

    Coming soon

  • Battle simulator

    Simulate fights for your party and search for the best skills, gear and party for a quest.

    Available

Command-line tools

Every tool also runs locally in Python. See the repository for setup and usage.
