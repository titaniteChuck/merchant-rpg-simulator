# Combat Simulator

[Root](../../index.md) > [Tooling](../index.md) > Combat Simulator

## Main concepts

- [combat-simulator](./combat-simulator.md) - TypeScript port of the game's combat: fights, map runs, party rules, rotation / gear / party searches, joint optimiser, potions, class balance.
- [schedule](./schedule.md) - Skill probe, effect tags and enemy 5-turn timelines; counter-schedule score for rotations.
- [warm-start](./warm-start.md) - Offline best rotation per class, tier and enemy; tried first by the rotation searches.
- [party-search](./party-search.md) - Smallest winning parties with rows, order, rotations and scrolls in one search.
